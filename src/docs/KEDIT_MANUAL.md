# KEDIT 1.6 사용 설명서

KEDIT는 애플 II 플러스에서 한글과 영문을 함께 쓰는 전체 화면 글 편집기입니다.
K-HANGEUL 한글 드라이버 위에서 돌아가며, 전부 6502 어셈블리로 만들었습니다. BASIC이나 K-BASIC은 필요 없습니다.

## 1. 필요한 것

| 항목 | 내용 |
|---|---|
| 기종 | 애플 II 플러스, 48K, 랭귀지 카드(16K) 또는 Saturn 128K 카드 |
| 운영체제 | DOS 3.3 |
| 한글 | K-HANGEUL 1.2b |
| 디스크 | `disk\KEDIT.dsk` (DOS, K-HANGEUL, 글꼴, KEDIT가 들어 있음) |

애플 IIe 이상에서도 돌아가게 만들었지만 시험하지는 못했습니다.

## 2. 시작과 끝

- **시작:** `KEDIT.dsk`로 부팅하면 K-HANGEUL을 읽은 다음 바로 편집기가 뜹니다.
  K-HANGEUL이 떠 있는 `]` 프롬프트에서는 `BRUN KEDIT`로 시작합니다.
- **끝:** `ESC`를 누르고 `Q`(또는 `끝`)를 친 다음 `RETURN`. `]` 프롬프트로 돌아갑니다.
- KEDIT는 BASIC 프로그램이 쓰는 메모리를 씁니다. 메모리에 있던 BASIC 프로그램은 없어집니다.

편집기가 뜨면 화면은 비어 있고, 왼쪽 위에 커서가 있으며, 맨 아랫줄에 `KEDIT 1.6   ESC: 명령   ESC H: 도움말`이 보입니다.

## 3. 화면

```
0-14줄   글 (한 줄 46칸. 영문 1칸, 한글 한 글자 2칸)
15줄     영 ABC 줄 12/39 칸 7 여유 7312 * DIARY      (반전된 상태 줄)
```

상태 줄에 나오는 것은 왼쪽부터 다음과 같습니다.

| 표시 | 뜻 |
|---|---|
| `한` / `영` | 한글 입력 / 영문 입력 (`Ctrl-A`로 바꿈) |
| `ABC` / `abc` | 영문 대문자 / 소문자 고정 (`Ctrl-Q`로 바꿈) |
| `줄 12/39` | 커서가 있는 줄 / 전체 줄 수 |
| `칸 7` | 커서가 있는 칸 |
| `여유 7312` | 글을 더 쓸 수 있는 바이트 수. 글을 치거나 지울 때마다 바뀝니다. 0이 되면 `메모리가 가득 찼습니다`가 나오고 더 쓸 수 없습니다 (한글 한 글자는 2~5바이트) |
| `*` | 저장한 뒤에 글을 고쳤음 |
| 이름 | 파일 이름. 없으면 `(이름 없음)` |

- 한 줄이 46칸보다 길면 다음 화면 줄로 이어서 보여 줍니다. K-HANGEUL 화면의 46칸을 모두 쓰므로 한글은 한 줄에 23자까지 들어갑니다. 화면 오른쪽 끝의 4화소(글자 한 칸 6화소보다 작음)는 K-HANGEUL이 글을 그리지 못하는 자리입니다. 맨 아랫줄(반전된 줄)은 이 자리도 KEDIT가 칠해서 화면 끝까지 채웁니다.
- 알림(저장했습니다, 찾지 못했습니다 등)도 상태 줄에 나오고, 다음 키를 누르면 사라집니다.
- `ESC`를 누르면 상태 줄이 반전된 채로 `명령:` 뒤에 명령을 치는 명령 줄이 됩니다.

## 4. 글 쓰기

편집기는 모드가 없습니다. 글자를 치면 커서 자리에 바로 들어갑니다.

### 한글

- `Ctrl-A`로 한글 입력과 영문 입력을 바꿉니다.
- 자판은 K-HANGEUL의 두벌식입니다.
- 된소리와 ㅒ, ㅖ는 아래 키로 칩니다.

| 글자 | ㄲ | ㄸ | ㅃ | ㅆ | ㅉ | ㅒ | ㅖ |
|---|---|---|---|---|---|---|---|
| 키 | `-` | `=` | `*` | `<` | `>` | `;` | `+` |

- 한글 입력 상태에서 위 일곱 기호를 글자 그대로 쓰려면 영문 입력으로 바꾸고 칩니다. 숫자와 다른 기호는 한글 입력 상태에서도 그대로 들어갑니다.
- Shift를 쓸 수 있으면 Shift + `R E Q T W`로 된소리를, Shift + `O P`로 ㅒ ㅖ를 칠 수도 있습니다.

### 영문 대문자와 소문자

- `Ctrl-Q`로 대문자 고정(`ABC`)과 소문자 고정(`abc`)을 바꿉니다.
- Shift를 누르고 치면 그 글자만 반대로 들어갑니다.

### Shift

| 기종 | Shift로 쓰는 키 |
|---|---|
| 애플 II 플러스 | Shift 키. 단, 키보드에 "Shift 키 개조"(`$C063` 연결)가 되어 있어야 합니다 |
| 애플 IIe 이상 | 애플 키(열린 사과 또는 닫힌 사과)를 누른 채로 칩니다 (시험하지 못함) |

개조하지 않은 II 플러스와 에뮬레이터의 II 플러스에서는 Shift가 듣지 않습니다. `Ctrl-Q`와 기호 키를 쓰십시오.

## 5. 키

### 커서 옮기기

| 키 | 동작 |
|---|---|
| `Ctrl-B`, `←`, `Ctrl-U`, `→` | 한 글자 왼쪽, 오른쪽 (한글은 한 글자씩). 모든 기종에서 같습니다. Shift 키 개조를 한 II 플러스에서는 Shift+`←`가 앞 글자를 지웁니다 (`Ctrl-S`와 같습니다) |
| `Ctrl-K`, `Ctrl-J` | 한 줄 위, 아래 (IIe의 `↑` `↓` 키가 이 코드를 보냅니다). 화면 맨 위나 맨 아래를 넘어가면 화면이 한 줄씩 밀립니다 |
| `Ctrl-O`, `Ctrl-N` | 줄의 처음, 끝 |
| `Ctrl-W`, `Ctrl-Z` | 한 쪽 위, 아래 |
| `Ctrl-T`, `Ctrl-E` | 파일의 처음, 끝 |

### 지우기

| 키 | 동작 |
|---|---|
| `Ctrl-S`, `DELETE` | 커서 앞 글자를 지웁니다. 치고 있던 한글 글자는 자모 하나씩 지우고 (안녕 → 안녀 → 안ㄴ → 안), 이미 끝난 글자는 한 글자를 통째로 지웁니다 (안 → 없음). 커서를 옮기거나 다른 키를 친 뒤에는 모두 통째로 지웁니다. 줄 맨 앞에서는 윗줄과 붙입니다. 모든 기종에서 같습니다. `←`는 지우지 않고 커서를 왼쪽으로 옮깁니다 (PC 키보드의 Backspace는 에뮬레이터에서 `←`로 들어가므로 `Ctrl-S`를 쓰십시오) |
| `Ctrl-D` | 커서 자리의 글자를 지웁니다. 줄 끝에서는 아랫줄을 붙입니다 |
| `Ctrl-X` | 커서부터 줄 끝까지 지웁니다 |
| `Ctrl-Y` | 줄 전체를 지웁니다. 지운 줄은 기억해 둡니다 |
| `Ctrl-G` | 커서가 있는 줄을 복사해 기억해 둡니다 (줄은 그대로). `Ctrl-P`로 넣습니다 |

### 되돌리기

| 키 | 동작 |
|---|---|
| `Ctrl-R` | 커서가 있는 줄을 고치기 전 모습으로 되돌립니다. 한 번 더 누르면 고친 모습이 다시 나옵니다 |
| `Ctrl-P` | 기억해 둔 줄(`Ctrl-Y`로 지운 줄이나 `Ctrl-G`로 복사한 줄)을 커서 줄 위에 넣습니다. 여러 번 넣을 수 있습니다 |

### 그 밖의 키

| 키 | 동작 |
|---|---|
| `RETURN` | 줄을 나눕니다 (새 줄) |
| `Ctrl-A` | 한글 / 영문 |
| `Ctrl-Q` | 대문자 / 소문자 |
| `Ctrl-F` | 같은 낱말을 다시 찾습니다 |
| `Ctrl-L` | 화면을 다시 그립니다 |
| `Ctrl-I` (Tab) | 빈칸 하나를 넣습니다 |
| `ESC` | 명령 줄을 엽니다 |

화면을 그리는 동안에도 키를 미리 칠 수 있습니다. 쪽 넘김 키를 여러 번 이어 누르면 화면은 마지막에 한 번만 그립니다.

## 6. 명령

`ESC`를 누르면 맨 아랫줄에 `명령:`이 나옵니다. 그 뒤에 명령을 치고 `RETURN`을 누르면 실행합니다. `ESC`를 한 번 더 누르면 그만둡니다.
명령 줄에서도 `Ctrl-A`로 한글과 영문을 바꾸고, `Ctrl-S`나 `←`로 지웁니다.
명령은 한글 이름과 영문 이름 어느 쪽으로 쳐도 됩니다. 영문은 대소문자를 가리지 않습니다.

### 파일

| 한글 | 영문 | 동작 |
|---|---|---|
| `저장 [이름]` | `W [이름]`, `SAVE` | 저장합니다. 이름을 주면 그 이름으로 저장하고, 그 뒤로는 그 이름이 파일 이름이 됩니다 |
| `열기 이름` | `E 이름`, `OPEN` | 파일을 엽니다. 없는 이름이면 새 파일로 시작합니다. 고친 글이 있으면 `저장할까요? Y:저장 N:버림 다른 키:취소`라고 묻습니다 (`새`와 같습니다). `E!`는 묻지 않고 버리고 엽니다 |
| `넣기 이름` | `R 이름` | 다른 파일을 커서 자리에 끼워 넣습니다 |
| `새` | `N`, `NEW` | 이름 없는 빈 글로 시작합니다. 저장한 글이면 바로 시작합니다. 고친 글이 있으면 `저장할까요? Y:저장 N:버림 다른 키:취소`라고 묻습니다. `Y`는 저장한 뒤 새 글을 시작하고 (이름이 없으면 `파일 이름이 필요합니다`가 나오고 그대로 남습니다. `저장 이름`으로 먼저 저장하십시오), `N`은 고친 것을 버리고 시작하고, 다른 키는 취소합니다. `N!`, `새!`는 묻지 않고 버립니다 |
| `목록` | `LS`, `CAT`, `DIR`, `LIST` | 디스크의 파일 목록 (잠금 표시 `*`, 종류, 섹터 수, 이름). 한 쪽이 차거나 목록이 끝나면 멈추고, `Ctrl-K` `Ctrl-J`로 줄을 고르면 그 줄이 반전됩니다. `RETURN`은 고른 파일을 엽니다 (고친 글이 있으면 위와 같이 묻습니다. 텍스트 파일이 아니면 열지 않습니다). `ESC`는 글로 돌아갑니다. 다른 키는 다음 쪽을 보여 주고, 마지막 쪽에서는 글로 돌아갑니다 |
| `복사` | `CP`, `COPY` | `Ctrl-G`와 같습니다. 커서 줄을 기억해 둡니다 |
| `붙임` | `PU`, `PASTE` | `Ctrl-P`와 같습니다. 기억해 둔 줄을 커서 줄 위에 넣습니다 |
| `끝` | `Q`, `QUIT` | 편집기를 끝냅니다. 고친 글이 있으면 거절합니다 |
| `끝!` | `Q!` | 저장하지 않고 끝냅니다 |
| `저장끝` | `WQ`, `X` | 저장하고 끝냅니다 |

파일 이름은 한글(`열기 일기`)도 영문도 됩니다.

### 찾기와 이동

| 한글 | 영문 | 동작 |
|---|---|---|
| `찾기 낱말` | `F 낱말`, `FIND`, `/낱말` | 커서 다음부터 낱말을 찾습니다. 파일 끝까지 없으면 처음부터 이어서 찾습니다. `Ctrl-F`로 다음 것을 찾습니다 |
| `줄 N` | `G N`, 또는 숫자만 | N번째 줄로 갑니다 |
| `번호` | `NU` | 줄 번호를 보이거나 숨깁니다 |

- 영문은 대소문자를 가리지 않고 찾습니다.
- 한글은 친 키대로 찾습니다. 그래서 `하`를 찾으면 `한`에서도 멈춥니다.

### 지우기

| 한글 | 영문 | 동작 |
|---|---|---|
| `지움 [N]` | `D [N]` | 커서 줄을 지웁니다. N을 주면 커서 줄부터 N줄을 지웁니다 |
| `문단지움` | `DP` | 커서 줄부터 다음 빈 줄 앞까지 지웁니다 |
| `모두지움!` | `DA!` | 글 전체를 지웁니다. 디스크의 파일은 저장하기 전까지 그대로입니다 |

### 알아보기

| 한글 | 영문 | 동작 |
|---|---|---|
| `정보` | `I` | 글의 크기와 남은 메모리를 바이트로 보여 줍니다 |
| `도움` | `H`, `HELP`, `?` | 키와 명령 목록을 보여 줍니다 |

## 7. 되돌리기의 한계

KEDIT에는 일반적인 "실행 취소"가 없습니다. 되돌릴 수 있는 것은 두 가지뿐입니다.

- **한 줄 안에서 고친 것:** `Ctrl-R`. 커서가 그 줄에 있는 동안만 됩니다.
- **지운 줄:** `Ctrl-P`. 마지막으로 지우거나 복사한 한 줄만 기억합니다.

다음은 되돌릴 수 없습니다.

- 줄을 붙이거나 나눈 것 (나눈 줄은 `←`로 다시 붙일 수 있습니다).
- `지움 N`, `문단지움`, `모두지움!`으로 지운 여러 줄 (마지막 한 줄만 `Ctrl-P`로 살릴 수 있습니다).
- `넣기`로 끼워 넣은 파일.

크게 고치기 전에 먼저 저장하십시오. 잘못되면 `E! 이름`으로 저장해 둔 파일을 다시 엽니다.

## 8. 제한

| 항목 | 한계 |
|---|---|
| 글의 크기 | 6,983바이트. 넘으면 `메모리가 가득 찼습니다`, 큰 파일은 `파일이 너무 큽니다` |
| 한 줄의 길이 | 250바이트. 더 긴 줄이 있는 파일은 열지 않습니다 (`너무 긴 줄이 있습니다`) |
| 파일 이름 | 30바이트 (한글 이름은 앞뒤 표시 2바이트 포함) |
| 명령 줄 | 60바이트 |
| 파일 종류 | DOS 텍스트 파일(T)만. 다른 종류는 `텍스트 파일이 아닙니다` |
| 드라이브 | 지금 쓰고 있는 드라이브만. 명령에서 드라이브를 고를 수 없습니다 |

- 한글 한 글자는 2~5바이트입니다 (한 = 3, 않 = 4). 한글이 이어진 묶음마다 2바이트가 더 듭니다. 한글만 쓰면 대략 2,400~2,900자입니다.
- 저장한 파일은 마지막 줄 끝에 항상 Return이 붙습니다.
- 저장은 먼저 `KEDIT.TMP`라는 임시 파일에 글을 다 쓴 다음, 옛 파일을 지우고 임시 파일의 이름을 바꿉니다. 그래서 쓰는 도중에 디스크 오류가 나도 옛 파일은 그대로 남습니다. 글은 메모리에도 남아 있으니 다른 디스크에 다시 저장할 수 있습니다.
- 디스크에 옛 파일과 새 파일이 함께 들어갈 자리가 없으면(`디스크가 가득 찼습니다`가 날 경우) 1.2처럼 옛 파일을 먼저 지우고 그 자리에 씁니다. 이때는 쓰는 도중 오류가 나면 옛 파일이 없습니다.
- 잠긴 파일에 저장하려 하면 `파일이 잠겨 있습니다`가 나오고 옛 파일은 그대로입니다. 다른 이름으로 저장하십시오.
- `KEDIT.TMP`는 KEDIT가 쓰는 이름입니다. 이 이름의 파일은 저장할 때 지워지므로 글 파일 이름으로 쓰지 마십시오.
- 만들지 않은 기능: 바꾸기, 거꾸로 찾기, Saturn 카드를 쓴 큰 파일.
- 시험하지 못한 것: 애플 IIe 이상에서의 동작 전체, 특히 애플 키를 Shift로 쓰는 것 (시험에 쓰는 MAME에 IIe ROM이 없습니다). 실제 기계에서의 동작. 저장 도중의 입출력 오류(디스크 불량)는 에뮬레이터에서 만들 수 없어 시험하지 못했습니다.
- `Ctrl-J`(아래)와 `Ctrl-K`(위)는 MAME 키보드로는 넣을 수 없어 (`Ctrl-J`가 Return으로 들어감) 키 코드를 직접 넣는 방법으로 시험했습니다.

## 9. 파일 형식

KEDIT가 만드는 파일은 K-HANGEUL의 글 형식(N-바이트)입니다. KS 완성형, 조합형, 유니코드가 아니라 **두벌식으로 친 키를 그대로** 담습니다.

| 내용 | 바이트 |
|---|---|
| 한글 묶음의 시작 | `Ctrl-K` (`$8B`) |
| 자모 키 | 두벌식 자판의 대문자, 비트 7을 켬 (ㄱ = `R` = `$D2`, ㅏ = `K` = `$CB`) |
| 한글 묶음의 끝 | `Ctrl-A` (`$81`) |
| 영문, 숫자, 기호 | ASCII, 비트 7을 켬 (빈칸 = `$A0`) |
| 줄 끝 | Return (`$8D`) |

예: `한글 123` → `8B C7 CB D3 D2 CD C6 81 A0 B1 B2 B3`

- K-HANGEUL 화면에 그대로 찍을 수 있고, K-BASIC과 kScheme의 소스 파일도 같은 형식입니다.
### PC에서 파일 바꾸기: `nbyte.py`

`disk` 폴더의 `nbyte.py`는 KEDIT 파일(N-바이트)과 PC의 UTF-8 글 파일을 서로 바꾸는 파이썬 프로그램입니다.
K-HANGEUL 프로젝트의 것을 그대로 옮겨 놓았습니다. 파이썬 3만 있으면 되고 다른 꾸러미는 필요 없습니다.

| 명령 | 하는 일 |
|---|---|
| `python nbyte.py decode 입력 출력` | KEDIT 파일 → UTF-8 글 파일 (줄 끝은 LF) |
| `python nbyte.py encode 입력 출력` | UTF-8 글 파일 → KEDIT 파일 |
| `python nbyte.py check 입력` | KEDIT 파일을 풀었다가 다시 만들어 원래와 같은지 확인 |

디스크 이미지에서 파일을 꺼내고 넣는 데는 AppleCommander(`acx`)를 씁니다. `disk` 폴더에서 다음과 같이 합니다.

**애플 → PC** (디스크의 `DIARY`를 PC에서 읽기)

```
acx -g KEDIT.dsk DIARY diary.nb
python nbyte.py decode diary.nb diary.txt
```

**PC → 애플** (PC에서 쓴 `memo.txt`를 디스크에 `MEMO`로 넣기)

```
python nbyte.py encode memo.txt memo.nb
acx -p KEDIT.dsk MEMO TXT 0 < memo.nb
```

- `TXT`는 대문자로 씁니다. 소문자로 쓰면 `acx`가 이진 파일(B)로 넣어서 KEDIT가 열지 못합니다.
- PC의 글 파일은 UTF-8로 저장합니다. 한글, 영문, 숫자, ASCII 기호만 쓸 수 있습니다. 한자나 그림 글자가 있으면 `encode`가 오류를 냅니다.
- KEDIT의 한계는 그대로입니다. 바꾼 파일이 6,983바이트를 넘거나 한 줄이 250바이트를 넘으면 열리지 않습니다.
- `acx`는 이름에 제어 문자를 받지 못해서 한글 이름 파일은 꺼내거나 넣지 못합니다. 영문 이름으로 넣은 뒤 KEDIT에서 `저장 한글이름`으로 다시 저장하고, 꺼낼 때는 반대로 영문 이름으로 저장한 뒤 꺼내십시오.
- 에뮬레이터가 디스크 이미지를 열고 있는 동안에는 `acx`로 넣거나 꺼내지 마십시오.

## 10. 알림 말

| 알림 | 뜻 |
|---|---|
| `저장했습니다` / `읽었습니다` / `넣었습니다` | 저장, 열기, 넣기가 끝났습니다 |
| `새 파일입니다` | 그 이름의 파일이 없어 빈 글로 시작했습니다 |
| `파일 이름이 필요합니다` | 이름 없는 글을 저장하려 했거나, 명령에 이름이 빠졌습니다 |
| `저장하지 않았습니다 (끝! 이나 Q! 로 나가기)` | 고친 글이 있습니다. 저장하거나 `!`를 붙이십시오 |
| `모두 지우려면 DA! 또는 모두지움!` | `모두지움`에는 `!`가 필요합니다 |
| `찾지 못했습니다` | 찾는 낱말이 없습니다 |
| `모르는 명령입니다` | 명령 이름이 틀렸습니다 |
| `메모리가 가득 찼습니다` | 글이 더 들어갈 자리가 없습니다 |
| `파일이 너무 큽니다` / `너무 긴 줄이 있습니다` / `텍스트 파일이 아닙니다` | 열 수 없는 파일입니다 (8장) |
| `파일이 없습니다` | `넣기`에 준 이름의 파일이 없습니다 |
| `쓰기 금지된 디스크입니다` / `디스크가 가득 찼습니다` / `파일이 잠겨 있습니다` / `입출력 오류` / `디스크 오류 N` | DOS의 디스크 오류입니다 |

삑 소리는 그 자리에서 할 수 없는 일을 뜻합니다 (파일 맨 앞에서 지우기, 되돌릴 것이 없을 때 `Ctrl-R`, 줄이 250바이트를 넘게 될 때 등).
